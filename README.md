# Nypuna Connect

Build Nypuna Connect, a comprehensive CBSE school management platform based on the 26-module SRS. Implement role-based workspaces for Administrator, Principal, Teacher, Front Office, and Librarian (no student or parent logins). Include the Student Information System (SIS), Admissions workflow, Academic setup (grades, sections, subjects, classrooms), smart Timetable scheduling with validation and teacher workload balancing, Attendance, Assignments, CBSE Examinations with report cards, Library circulation, School Council electronic voting, House points ledger, Front Office visitor logs, and smart file management using Lovable Cloud.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://nypuna-school-hub.lovable.app
